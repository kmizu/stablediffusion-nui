**Prompt Tools** タブは、プロンプト入力の繰り返しを減らすための道具をまとめたものです。A1111 拡張の
Multi-Prompt Manager(プロンプト保存)、Prompt All in One(タグ編集・履歴・お気に入り・ブラックリスト)、
D2 Prompt Selector(YAML のタグボタン)、Easy Tag Insert(タグカード)にあたる機能を、アプリ本体の機能として
備えています。翻訳機能は含みません(ページ末尾を参照)。

![Prompt Tools タブ](shots/prompt-tools.png)

上部の **Target tab** で、書き込む先の生成タブ(txt2img、img2img、Inpaint)を選びます。直前に開いていた生成タブが
自動で選ばれます。その下の 2 つのボックスには、そのタブのプロンプトとネガティブプロンプトがそのまま表示されます。
**Insert into the negative prompt** にチェックを入れると、タグボタン、カード、タグ編集がネガティブ側に働きます。
ボックスの下の 1 行には、直前の操作の結果が出ます。

## 保存したプロンプト

テキストに名前を付けて **Save** します。名前が空なら `prompt 1`、`prompt 2` のように付きます。ネガティブ用なら
**This is a negative prompt** にチェックします。**Use** は対象タブのプロンプト(またはネガティブ)をそのテキストで
置き換え、**Copy from active prompt** は逆に対象タブの内容をテキスト欄に写します。**Rename**、**Delete**(確認あり)、
**Import…**、**Export…** も使えます。保存先は `config/prompt-tools/prompts.json` で、Multi-Prompt Manager と同じ形式なので
やり取りできます。

## 履歴とお気に入り

Generate や Queue を押すたびに、そのプロンプトとネガティブプロンプトが履歴に入ります(新しい順、500 件まで。同じ組は
重複せず先頭に移ります)。**Restore** で両方を対象タブに戻せます。**Bookmark selected** は履歴の項目をお気に入りへ、
**Bookmark current** は今のボックスの内容をお気に入りに加えます(名前は任意)。履歴を消してもお気に入りは残ります。

## タグ編集

プロンプトのタグを一覧にします。**Up** / **Down** で並べ替え、**Weight +0.1** / **Weight -0.1** で `(tag:1.2)` 形式の
重みを変えます(重み 1.0 では素のタグに戻り、`<lora:…>` は変更しません)。**Delete tag** で削除、**Remove duplicates** で
重複タグの 2 つ目以降を消します。括弧の中のカンマではタグを区切りません。これらのボタンを使うと欄は `a, b, c` の形に
書き直されるため、改行は残りません。

**Blacklist**(1 行に 1 タグ)は **Apply blacklist** を押したときだけ適用され、重みや大文字小文字に関係なく該当タグを
取り除きます。

## タグボタン

`config/prompt-tools/tag-selector` に YAML ファイルを置きます(**Folder…** で別のフォルダも指定できます。クラウドドライブ上でも
構いません)。ファイル 1 つが 1 つのタブです。グループにはタグのリスト、または「名前: タグ」の対応を書け、入れ子にもできます。

```yaml
髪色:
  単色:
    - black hair
    - blonde hair
  複数色:
    グラデーション: gradient hair
品質:
  - masterpiece
```

* ボタンを押すとそのタグがプロンプトに追加されます(すでにあるタグは重ねて入りません)。
* グループ名のボタン(オレンジ色)を押すと、そのグループ(下位グループを含む)からランダムに 1 つ入ります。
* **Ctrl を押しながらクリック** でネガティブに追加、**右クリック** でプロンプトから削除します。
* ボタンに重ねると、入るテキストが下に出ます。検索欄は、全ファイルからボタン名またはタグで探します。
* `__config__.yml` の `sort:` にファイル名を並べると、タブの順番を決められます。残りはアルファベット順です。
* 読めないファイルは `(!)` 付きで表示され、問題の行が出ます。読めるのはブロック形式のマップとリスト、引用符付き・なしの
  文字列、`[a, b]` 形式のリストです。アンカー、複数行テキスト、`{}` 形式のマップは使えません。

初回は、タブが空にならないよう小さな `sample.yml` が作られます。

## タグカード

カードは短いテキストで、`config/prompt-tools/tag-cards/<カテゴリ>/<名前>.tag` として保存されます。カテゴリごとに
まとまって表示されます。クリックで挿入、右クリックで「ネガティブに挿入」「プロンプトから削除」「編集」が選べます。
作るときは **Category**(`/` でサブフォルダ)、**Name**、テキストを入れて **Save card** を押します。名前に
`< > : " / \ | ? *` は使えず、カードがカードフォルダの外に書かれることはありません。

## 含まれないもの

Prompt All in One にある、オンライン・オフラインの **翻訳**、ChatGPT によるプロンプト生成、LoRA や Embedding の語の
ハイライト、数千語の内蔵タグ辞書、テーマ、タグのドラッグ操作はこのタブにはありません。タグ編集は、タグを消さずに
無効化することもできません。
