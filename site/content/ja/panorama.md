**Panorama** タブは、正距円筒図法(縦横比 2:1)の画像やキューブマップの展開図(4:3)を、見回せる 360° の景色として表示します。
A1111 拡張「Panorama Viewer」に相当する機能です。このタブを開いている間は、メインウィンドウ右側のプレビューとギャラリーを隠し、画面の幅いっぱいを使います。

![Panorama タブ](shots/panorama.png)

## 画像を開く

* プレビューの下の **Pano** ボタン、ギャラリーの右クリックメニューの **View as panorama**、[画像ブラウザ](image-browser.html)の **Send to panorama** から開けます。
* **Open…** でファイルを選ぶか、ビューアに画像ファイルをドロップします。
* **◀ ▶** で同じフォルダの前後の画像に移ります(自然順、端は反対側につながります)。

画像の形から投影方式を選びます。2:1 は **Equirectangular**、正方形の面でできた 4:3 は **Cubemap: Polyhedron net**、それ以外は正距円筒図法として表示し、ビューアの下にヒントを出します。**Projection** の一覧で切り替えられます。キューブマップにできない形(面が正方形でない画像)を選ぶと、理由を表示して拒否します。
正距円筒図法なら 2:1(例 1024x512)、キューブマップなら 4:3(1024x768)で生成してください。一般的な Stable Diffusion のモデルは左右の端をつなげて描かないので、継ぎ目が見えるのは普通です。Inpaint で直せます。

## 見回す

| 操作 | 結果 |
|---|---|
| ドラッグ | カメラを回します(景色がポインタについてきます)。 |
| ホイール、**+** / **-** | ズーム(視野角 20° から 120°)。 |
| 矢印キー | 視野角の 1/18 ずつ回します。 |
| ダブルクリック、**Home**、**Reset view** | 視野角 90° で正面に戻します。 |
| **Yaw**、**Pitch**、**FOV** | 数値で正確に指定します。 |
| **Front / Back / Left / Right / Up / Down** | 視野角を変えずに、対応する方向へ向きます。 |
| **Auto-rotate** | ゆっくり右へ回ります(速度は 1 秒あたりの度数)。 |
| **Fullscreen** | カメラを共有する全画面ウィンドウを開きます。**Esc** で閉じます。 |

動かしている間は粗く、止まるとくっきり描き直します。

## 変換と保存

* **→ Cubemap** は正距円筒図法の画像を、面の大きさが幅の 1/4 の 4:3 展開図に変換します(1024x512 は 1024x768 になります)。**→ Equirectangular** は展開図を元に戻します。結果は出力フォルダの `panorama` フォルダに `<名前>-cubemap.png` または `<名前>-equirect.png` として保存し、生成パラメータを引き継いで、すぐに表示します。変換は再サンプリングなので、往復するとわずかにぼやけます。
* **Save view** は、いまカメラに見えている景色を幅 1600 px の PNG(`<名前>-view.png`)として保存します。
* **⇢ img2img**、**⇢ Inpaint**、**⇢ Extras** で、表示中の画像を送ります(極の部分を直すために展開図を Inpaint に送る、など)。

[Image Scrambling](tools.html) のパスワード保護セッション中は、保護された画像をメモリ上でだけ復号し、このタブが保存する画像もスクランブルして書き出します。

## 動画を開く

自分で用意した ffmpeg と、同じフォルダにある ffprobe を使い、正距円筒の動画を再生できます。**Choose ffmpeg…** で ffmpeg を選び、**Open video…** から動画を開いてください。再生・一時停止、位置指定、速度変更ができます。ffmpeg は同梱・自動取得しません。利用する ffmpeg の配布元とビルドに付属するライセンス条件を確認してください。終端付近では表示時刻より最大 2 秒前のフレームを表示する場合があります。

## 未対応

Infinite Zoom からの動画送信、4x3 の十字以外のキューブ配置、openOutpaint への送信は提供していません。
