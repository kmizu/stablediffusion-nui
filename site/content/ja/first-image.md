このページでは、**txt2img** タブで画像を 1 枚生成するまでの流れを説明します。事前に[インストールと初回起動](install.html)を済ませ、チェックポイントを 1 つ以上使える状態にしておいてください。

以下の画面名は英語表示に合わせています。日本語表示では、たとえば **Checkpoint** は「チェックポイント」、**Prompt** は「プロンプト」、**Generate** は「生成」です。切り替え方は[表示言語](localization.html)を参照してください。

![txt2img タブの生成フォーム](shots/txt2img-form.png)

## 1. チェックポイントを選ぶ

1. **txt2img** タブを開きます。
2. 画面上部のバーで **Checkpoint（チェックポイント）** の右にあるボタン（未選択なら **Select checkpoint…（チェックポイントを選択…）** と表示されます）を押します。
3. 一覧が開くので、名前の一部を入力して絞り込み、使うチェックポイントをクリックするか Enter キーで選びます。

選ぶとモデルの読み込みが始まり、右側の状態表示が **● Loading** に変わります。**● Ready** に戻れば生成できます。ボタンには、名前と並んでモデルの種類が表示されます。プレビュー画像を見ながら選びたいときは **Models…** を押します。

一覧にチェックポイントが出てこない場合は、**⟳**（Rescan model folders）を押してモデルフォルダを読み込み直してください。それでも出ない場合は[トラブルシュート](troubleshooting.html#models)を参照してください。

上部バーでは、ほかに次の項目も設定できます。

| 項目 | 内容 |
|---|---|
| **VAE** | **Automatic** にすると、チェックポイントに含まれる VAE を使います |
| **Clip skip** | 1 が通常の設定です。アニメ系のモデルでは 2 がよく使われます |

## 2. プロンプトを書く

**Prompt** の欄が 2 つあります。

- 上の欄（プロンプト）: 描きたいものを書きます。
- 下の欄（ネガティブプロンプト）: 避けたいものを書きます。

欄の右上には、おおよその CLIP トークン数と、いまのチャンク（75 トークン単位）の上限が表示されます。括弧の閉じ忘れなどがあると、欄の右下に警告が出ます。

語句を選択して Ctrl+↑ / Ctrl+↓ を押すと、`(語句:1.1)` のような強調の重みを増やしたり減らしたりできます。LoRA を使う場合は **✚ LoRA** を押して検索し、カーソル位置に `<lora:name:1>` タグを挿入します。

## 3. サンプリングの設定

**Sampling（サンプリング）** カードで次の項目を設定します。

| 項目 | 初期値 | 目安 |
|---|---|---|
| **Sampler（サンプラー）** | DPM++ 2M | エンジンが対応しているサンプラーだけが表示されます。右側はノイズスケジュールで、**Automatic** ならサンプラーの既定のスケジュールを使います |
| **Steps（ステップ数）** | 20 | ノイズを取り除くステップ数です。20〜30 が一般的です |
| **CFG Scale** | 7 | プロンプトにどれだけ忠実に従うかです。5〜8 が一般的です |

## 4. 画像サイズを決める

**Size（サイズ）** カードの **Width（幅）** と **Height（高さ）** で画像の大きさを指定します。どちらも 8 の倍数です。

- **⇅** を押すと、幅と高さを入れ替えます。
- **▦** を押すと、よく使うサイズを選べます。SD1.5 では 512〜768、SDXL では 100 万画素前後（1024 × 1024、832 × 1216 など）が目安です。

**Batch** の **count** は続けて実行する回数、**size** は同時に生成する枚数です。size を増やすと VRAM を多く使います。生成される枚数の合計は **Total** に表示されます。最初は両方 1 のままにしておくとよいでしょう。

## 5. seed を決める

**Seed（シード）** に -1 を入れると、毎回ランダムな seed を使います。同じ seed と同じ設定で生成すると、同じ画像を再現できます。

- **⚄** を押すと、-1（ランダム）に戻します。
- **♻** を押すと、直前に生成した画像の seed を入れます。

## 6. 生成する

画面下部のバーにある **▶ Generate（生成）** を押すか、Ctrl+Enter を押します。プロンプトの入力中でも Ctrl+Enter で生成できます。

生成中は、ボタンが **■ Interrupt（中断）** に変わります。途中でやめるときは、このボタンを押すか Esc キーを押します。進捗はボタンの右側のバーと、ステップ数の表示で確認できます。

同じ設定のジョブを続けて予約したいときは **＋ Queue**（Ctrl+Shift+Enter）を押します。

### ライブプレビュー

生成中は、途中経過の画像がプレビュー欄に表示され、左上に **LIVE PREVIEW** と出ます。何ステップごとに更新するかと表示方法は、Settings の **General** タブの **Live preview** と **Preview method** で変えられます。**Live preview** を 0 にすると、ライブプレビューは表示されません。

| Preview method | 内容 |
|---|---|
| `approx` | すぐに表示されますが、色はおおまかです |
| `taesd` | 画質がよくなりますが、少し処理が増えます |

## 7. 結果を確認する

生成が終わると、プレビュー欄に完成した画像が表示されます。

- Ctrl + マウスホイールで拡大・縮小します。
- ドラッグで表示位置を動かします。
- ダブルクリックで、画面に合わせる表示と等倍表示を切り替えます。

### パラメータの表示欄

画像の下には、ファイル名と、その画像の生成パラメータ（プロンプト、seed、サンプラーなど）を表示するテキスト欄があります。この欄の内容はコピーして使えます。

その下のボタンで、表示中の画像に対して次の操作ができます。

| ボタン | 動作 |
|---|---|
| **⇢ img2img** | 画像とパラメータを img2img タブに送ります |
| **⇢ Inpaint** | 画像とパラメータを Inpaint タブに送ります |
| **↺ Restore** | 画像の生成パラメータを、いま開いているタブに戻します |
| **Send to Comparison** | **Comparison** タブで比較します。初期設定では表示されません |
| **⧉** | 画像をクリップボードにコピーします |
| **▤** | 画像のあるフォルダを開きます |
| **🗑** | 画像を削除します（確認があります） |

**↺ Restore** では、画像に記録されたチェックポイントが見つかり、いまのチェックポイントと違う場合は、そのチェックポイントに切り替えます。見つからない場合は、いまのチェックポイントのまま、ほかのパラメータだけを戻します。VAE も、見つかれば切り替え、見つからなければいまの選択のままにします。

### ギャラリー

生成した画像はギャラリーに並びます。

- 検索欄にプロンプトの語句やファイル名を入力すると、絞り込めます（すべての語を含むものだけが残ります）。
- プレビューにフォーカスがあるときは、← / → キーで前後の画像に移れます。
- 選択中の画像は Delete キーで削除できます。
- 右クリックのメニューから、**Send to img2img**、**Send to Inpaint**、**Restore parameters**、**Copy image**、**Copy parameters**、**Show in folder**、**Delete…** などが使えます。
- **All images** の欄で今回のセッションの生成を 1 つ選ぶと、**Save ZIP…** でその生成の画像をまとめて ZIP に保存できます。

## 8. 保存された画像

画像は生成のたびに自動で保存されます。保存先は出力フォルダ（初期設定ではアプリのフォルダの `outputs`）の下で、モードと日付ごとに分かれます。

```
outputs/txt2img/2026-11-01/00000-1234567890.png
```

ファイル名は、通し番号と seed です。ほかの種類の画像も、種類ごとのフォルダに保存されます。出力フォルダは Settings の **General** タブの **Output folder** で変えられます。

PNG には、生成パラメータが A1111 と同じ `parameters` というテキスト情報として埋め込まれます。あとからこの画像を **PNG Info** タブに読み込めば、パラメータを確認して **⇢ txt2img**、**⇢ img2img**、**⇢ Inpaint** で各タブに送れます。A1111 や reForge で作った PNG も同じように読み込めます。

!!! note "画像を共有するとき"
    PNG にはプロンプトなどの生成パラメータがそのまま含まれます。他の人に渡す前に、含まれている情報を確認してください。

## 次のステップ

- 画像の一部を描き直すには、**⇢ Inpaint** で Inpaint タブに送り、マスクを描いて生成します。
- 生成モードや Hires. fix などの詳しい使い方は、[生成のガイド](generate.html)を参照してください。
