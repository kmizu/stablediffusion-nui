Stable Diffusion NUI は、ラベル、ボタン、タブの名前、ツールチップ、入力欄の案内文、ドロップダウンの項目を別の言語で表示できます。A1111 の言語パック拡張と **Bilingual Localization** 拡張が行うことを備えていて、同じパックのファイルを使います。

![日本語表示の txt2img タブ](shots/localization-ja.png)

## 言語を選ぶ

**Settings**(⚙)の **Language** タブを開きます。

![Language タブで内蔵の日本語パックと英語の併記を選んだ例](shots/localization-settings-ja.png)

| 項目 | 意味 |
|---|---|
| **Language** | 使うパック。**None (English)** で翻訳をやめます。**日本語 (ja_JP, built in)** はこのアプリのために書いたパックです。自分で追加したパックはファイル名で表示されます。 |
| **Fallback pack** | 1 つ目のパックにない文言のための 2 つ目のパック。たとえば内蔵パックの後ろにダウンロードした A1111 のパックを置けます。 |
| **Display** | **Translation only**(翻訳だけ)、**Bilingual (two lines)**(2 行)、**Bilingual (one line)**(1 行)。タブの名前、ウィンドウのタイトル、ドロップダウンの項目は常に 1 行です。 |
| **Order** | 併記のとき **Translation first**(翻訳が先)か **Original first**(英語が先)。 |
| **Translate tool tips**、**Translate drop-down items** | この 2 つは別々にオフにできます。 |

**OK** を押すと、再起動なしですぐ画面が変わります。変わるのは表示だけです。ドロップダウンの値(サンプラー、スケジュール)、入力欄に打った文字、生成パラメータ、PNG のメタデータ、MCP は英語のままです。いつでも English に戻せて、すべての文言が元どおりになります。

## 言語パック

パックは A1111 の言語ファイルです。英語の文言をキー、翻訳を値にした JSON オブジェクトです。アプリは次の場所の `.json` ファイルを探します。

- アプリの `localizations` フォルダ
- `plugins-ext/名前/localizations` と `extensions/名前/localizations`。言語パック拡張をここへ置けば、取り込み直さなくても使えます。
- **Extra pack folders** に追加したフォルダ(`localizations` フォルダ、拡張のフォルダ、A1111 のインストール先)

タブのボタン:

- **Download pack…** は A1111 コミュニティの言語パック(ウクライナ語、中国語、韓国語、タイ語、スペイン語、イタリア語、ドイツ語、日本語、ポルトガル語、トルコ語、ノルウェー語、ロシア語、フィンランド語、旧 A1111 パック。合計 35 ファイル)を一覧にします。選んだファイルは作者のリポジトリから決まったバージョンでダウンロードし、保存してある SHA-256 と照合したうえで、出どころとライセンスのメモと一緒に `localizations` に保存します。ボタンを押すまで何もダウンロードしません。
- **Import pack file…** は `.json` ファイルを `localizations` にコピーします(同名のファイルは上書きしません)。
- **Export untranslated strings…** は、表示されたのに翻訳がない英語の文言を、空のパックとして書き出します。値を埋めて取り込めば、残りを翻訳できます。
- **Reload list** はフォルダを読み直します。

拡張の記法も使えます。正規表現は `"@@/^(\\d+) images$/": "$1 枚"`、範囲指定は `"##tab_ti##Normal": "..."`(その id の要素の下だけ)と `"##@.card .btn##Lora": "..."`(型・id・スタイルクラスの簡単なセレクタ)です。

## どこまで翻訳されるか

2026年11月2日の実画面で、全タブと3つの生成モードを開いて測定したところ、内蔵の日本語パックは重複を除く英語の文言 1,947 件中 1,442 件（74.1 %）に対応しました。表示箇所ごとに数えると、文字を含む 4,902 箇所中 3,947 箇所（80.5 %）です。100文字を超える文言は 110 件中 21 件が訳されており、拡張コントロールの長いツールチップは多くが英語のままです。

A1111 コミュニティのパックは A1111 の言い回しを使うため、以前の測定ではこのアプリの文言の 2 % から 18 % に当たりました（検証ドキュメントを参照してください）。リストや表の中の文字、タイミングを含む進捗の行、エラーメッセージは、パックにメッセージ全体に合うルールがない限り英語のままです。
