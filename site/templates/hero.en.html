Stable Diffusion,
without the browser.

Stable Diffusion NUI is a desktop app that runs SD1.5 and SDXL models on your own GPU. Many A1111 extensions are built in, and AI agents can drive it over MCP.

Download for Windows Read the install guide

The download is for Windows x64 and includes a Java runtime. You supply Python 3.10–3.12 and your models. An NVIDIA GPU is recommended for generation.
