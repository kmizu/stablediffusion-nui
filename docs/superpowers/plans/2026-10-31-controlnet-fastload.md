# ControlNet Fastload (#17) Implementation Plan

**Goal:** Preserve the pinned extension's complete ControlNet data, images, loading/saving modes, viewer/filter and programmatic workflows in native NUI, without executing untrusted pickle.

**Architecture:** A bounded non-executing pickle opcode interpreter reconstructs only explicitly modeled primitive containers, NumPy arrays and known ControlNet unit records; unknown classes/opcodes fail with context, never execute constructors/imports. The original marker + gzip envelope is retained; writers emit compatible declarative legacy payloads and preserve all recognized original fields. Native UI uses the existing ControlNet form and settings with a dedicated reader/viewer and filter; generation uses per-job immutable capture, not global callbacks. Image-scrambling policy must protect embedded source images and avoid plaintext sidecars unless explicitly requested.

**Scope boundaries:** Pinned upstream `pk5ls20/sd-webui-controlnet-fastload` bbdb929f4285ea69d5099268496e4322dc7203ab, Apache-2.0. Load only/save only/load-save; occupied unit precedence; original images and masks, standalone .cni / appended image / both; preview, attribute filters, paging and send to both modes; programmatic equivalent of version/fetch/view. Unknown valid upstream values must be retained or rejected explicitly, not silently dropped. A1111 HTTP routes and NUI's JSONL/MCP transport have different ownership: choose an explicit native adapter with testable equivalent capability and document exact compatibility.
