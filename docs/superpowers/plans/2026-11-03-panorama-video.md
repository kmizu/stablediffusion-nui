# #21 パノラマ動画の実装計画（作業中）

目的はローカルの正距円筒動画を既存 Panorama タブで再生し、再生中も方向と拡大を操作できるようにすること。上流には Infinite Zoom の動画から送る導線があるが、本体の #64 が未実装なので、直接連携は残作業として記録する。現時点で #21 全体の完了を主張しない。

1. `core/panorama/LatestFrame.scala` と `LatestFrameSuite` で描画中と最新待機各 1 件に制限する。遅い描画中の入力増加と close をテストする。これは動画 UI にはまだ接続されていない。
2. JavaFX media 21.0.6 を追加した小さな実 GUI 試験を先行し、実動画の複数の異なるフレームを取得できるか、ローカルファイル、pause、seek、dispose、未対応形式のエラー、Windows jar 内のネイティブライブラリを確認する。失敗した場合は選択肢を再検討し、動かない仮定のまま UI を作らない。
3. `PanoramaTab` で動画選択、再生・一時停止、位置の変更、停止と終了時の release を接続する。新しい動画／静止画を開くと前の要求を無効にし、古い非同期結果を表示しない。動画パスを静止画送信・変換・メタデータ読み出しに渡さない。画像保護セッションも考慮する。
4. `PanoramaViewport` は描画中の古いフレームを破棄し続けて停止しないよう latest-frame 制御を使う。フルスクリーンは同じ再生時刻とカメラを共有する。負荷を制限し、エラーと close の競合を試験する。
5. 生成した方向色付き短動画と、既存の SD1.5／SDXL 実画像から作った動画で、実 MainWindow の再生・seek・カメラ・終了、スクリーンショットを確認する。保護状態と壊れた入力、codec、寸法上限、複数回切替も検証。製品版のパッケージでも同じ操作を確認する。
6. 日本語の使用方法、ライセンス、対応 codec、検証結果と未対応の Infinite Zoom 連携を記録する。issue の完了と台帳の done は、全体の受け入れ後に判断する。
