# #22: MCP から保存プロンプトを読む（部分対応）

`config/prompt-tools/prompts.json` の既存ライブラリを、MCP の `prompt_library` で読み取る。`list` は順序を保ち、名前と negative フラグのみをページ単位で返す。`get` は完全一致する一件の本文とフラグを返す。設定されたアプリのホーム以外のファイルを引数で指定させず、更新・削除・自動適用・生成は行わない。ページ数と本文長は制限し、未存在・不正な引数や読み込みエラーは明示する。既存 UI のデータ形式を変更しない。

検証は実際の MCP サーバー呼び出しで一覧・取得・ページング・不正引数・データ不変をテストする。続けて公式 SDK からツールを発見・呼出できるか確認する。これは上流 Prompt All in One の翻訳などを実装するものではなく、#22 の完了や台帳更新には使わない。
