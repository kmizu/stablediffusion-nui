# 保存プロンプトを MCP から読む

`prompt_library` は Prompt Tools の保存プロンプトを読み取る。サーバーのホームにある `config/prompt-tools/prompts.json` を対象とし、外部パス指定・保存・削除・生成は行わない。ファイル自体がシンボリックリンクの場合は読み込まない。この検査は親ディレクトリの junction やシンボリックリンクの差替えまでは保護しないため、アプリのホームは信頼できる場所に置く。

- `{"action":"list"}` は名前と `negative` フラグだけを返す。`limit` は 1〜100（省略時 100）、`offset` は 0 以上。続きがある場合は `next_offset` を使う。並行編集があるとページの位置が変わる。
- `{"action":"get","name":"quality"}` は名前が完全一致する一件の `prompt` と `negative` を返す。見つからない場合や本文が長すぎる場合はエラーになる。

保存内容は接続した MCP クライアントに渡る。未作成のライブラリは空一覧として扱い、ファイルは作成しない。これらは #22 の部分対応で、翻訳などの残機能を実装したものではない。

読み込みは最大 20 MiB、個別に返す本文は最大 100,000 文字。これらを超える場合はエラーにする。検証では 20 MiB を超えるファイルと 100,001 文字の本文を拒否し、元データを変更しないことを確認した。実行中のファイル追記・置換競合、親ディレクトリのリンク差替えは実験していない。
