# v0.8 verification record (2026-11-09)

`mosaic_outpaint` (#88): img2img Script, own design (no upstream code). Extends the init image on chosen sides in several passes: each pass
grows the canvas, pre-fills the strip (mirror / edge / gray), masks the strip plus an overlap into the old image, and inpaints it with the
img2img prompt, strength and mask blur; the next pass starts from the previous result. Works with any checkpoint (no ControlNet).

Checks: `MosaicOutpaintSuite` (canvas growth per pass, mask and blur settings reach the inpaint call, only the last result is returned,
argument validation) and the full plugins suite. Real GUI check (`RealMosaicOutpaintCheck`, real `MainWindow` img2img tab, scala-torch, RTX 3090,
SD1.5 `animekawa_v10`, 512x512 source generated earlier, +256 px right in 2 passes, strength 0.8): 768x512 result, infotext
"Script: Mosaic outpaint, pass 2/2"; image viewed: the meadow continues to the right with new sky, trees and flowers; the seam is visible
because a regular (non-inpainting) checkpoint was used.

Not covered: SDXL run, an inpainting-specific checkpoint, left/top/bottom extensions in the real GUI (covered only by unit tests).
