# scala-torch backend coverage (2026-11-08)

Which NUI plugins and engine requests work without Python (`SDFX_ENGINE_BACKEND=scala-torch`).
Generated by comparing `plugins/` with the native worker's `features()` and request dispatch in
`scala-torch/models/.../worker/NativeDiffusionBackend.scala`, and `python/sdfx/hooks.py` `KNOWN_HOOKS` / `server.py` request types.

## Summary

- Engine hooks: all 46 known hooks are advertised by the native worker (`deepcache` added 2026-11-09, scala-torch 0.1.3-gh18).
- Engine request types: every request type the Python server accepts is dispatched by the native worker.
- Python-only capability flags: `cv2`, `torchvision` (dependency probes, not features).
- "Implemented" does not mean "verified on a real model". Verified on the jar with images inspected (issues #139, #146-#151):
  txt2img, img2img, inpaint (SD1.5/SDXL), soft_inpainting, inpaint_difference, 14 samplers + schedulers (Karras, Exponential,
  Simple, Align Your Steps, Beta), hires fix (Latent upscaler, resize/steps/sampler/prompt overrides), ControlNet canny (SD1.5 and SDXL) and tile, multiple units, guidance interval, control modes, R-ESRGAN 4x+ hires upscaler,
  LoRA (single and multiple, SDXL, merged into FP16 weights), DeepCache (SDXL 0.53 -> 0.22 s/step, SD1.5), VAE swap (SD1.5, SDXL), Textual Inversion (EasyNegative, SD1.5).
