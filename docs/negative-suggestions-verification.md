# Negative prompt suggestions verification

The prompt editor offers three optional candidate sets (quality, anatomy, text and marks) and individual terms. Adding a set checks its terms without clearing prior selections; users can change the checks and see the selected terms before explicitly appending them to the active negative prompt. Nothing is selected or applied automatically. Existing exact top-level tags are skipped case-insensitively; weighted expressions are treated as distinct and existing text, whitespace and line breaks are not rewritten. Unfinished brackets or a trailing escape block insertion with an explanatory message. Candidate descriptions are shown in Japanese tooltips when Japanese is active, while insertion always uses the English text. Presets are independent of saved Styles and Prompt Tools libraries. Their effect depends on the model.
