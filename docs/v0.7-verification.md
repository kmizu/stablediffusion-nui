# v0.7 verification record (2026-11-09)

`gif2gif` (#53): img2img Script plugin, own implementation with the JDK's ImageIO (no new dependency). It reads every frame of a GIF
(composited on the logical screen, common disposal modes), runs img2img per frame (prompt, strength and seed from the img2img tab;
size = frame size) and writes a looping GIF with the original frame delays into a user-given folder (never overwrites); each processed
frame is also returned.

Checks: `Gif2GifSuite` (GIF round-trip of frame count, size, delay and colours; per-frame img2img with the frame as init image;
no overwrite) and the full plugins suite. Real GUI check (`RealGif2GifCheck`, real `MainWindow` img2img tab, scala-torch, RTX 3090,
SD1.5 `animekawa_v10`, 4 frames made from real generations, strength 0.5, fixed seed): 4 frames out, 256x256, delay 12 cs kept, GIF loops;
frames viewed (each frame is restyled to watercolor while keeping its pose and colours).

Not covered: SDXL run (the plugin is model-agnostic; not run), GIFs with transparency or local colour tables beyond what ImageIO
composites, MP4/WEBP input, per-frame prompts, temporal smoothing (the original extension's options beyond the basic extract/recombine).
